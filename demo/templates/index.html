    How it works

    1. Review textRaw English review
    2. PreprocessingExpand contractions, lowercase, strip punctuation and extra spaces
    3. MPNet embeddingFine-tuned all-mpnet-base-v2, 768-d, L2-normalized
    4. One-vs-rest classificationOne logistic regression per aspect
    5. Per-aspect thresholdsEach aspect has its own cut-off, tuned for F1 on validation data
    6. Aspect predictionsEvery aspect that passes its threshold

    Why multi-label?

    Reviews rarely talk about one thing. "Tasty food but overpriced" is about food and price. A single-label classifier would have to pick one and drop the other. Here each aspect is a separate yes/no decision, so a review gets as many labels as it deserves. In the dataset a review mentions about two aspects on average (1.97).

    Model card

    Embedding model
    sentence-transformers/all-mpnet-base-v2
    Fine-tuning
    Pairwise fine-tuning with cosine-similarity loss: two training reviews should be as similar as their aspect sets overlap (Jaccard). 2,862 pairs, 3 epochs, training split only
    Classifier
    One-vs-rest logistic regression, implemented from scratch in NumPy (gradient descent, C = 10, balanced class weights)
